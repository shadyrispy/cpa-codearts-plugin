# v0.1.18

修复流式请求的首帧额度错误与空回复边界，包含已经合并的 PR #7。

- CodeArts 把额度或限流错误放在 HTTP 200 SSE 正文时，如果尚未开始回答，插件把错误状态交给 CPA，使其可以对账号进行正常的错误处理及路由。
- 首帧仅有 role、空 delta、usage、心跳或 `[DONE]` 不再被误认作回答；这些元数据暂存至出现正文、推理内容或工具调用。元数据和错误即使落在同一读取中，也不会对客户端发送假成功。
- 已经开始回答的流保留已有内容及帧序，之后发生的错误仍在流中报告，避免把部分回答重放到别的账号。
- 上游在请求期限内始终不回答时返回 HTTP 504；空流返回 HTTP 502。未交给 CPA 的流不会再同时发送流内超时错误，且上游连接、会话与本地并发名额正常释放。
- 新增元数据、同批次答案与错误、超时、原生/Anthropic 协议回归测试；真实 CPA v7.3.9 宿主验证流式 403 和常规模型调用。发布 CI 还执行 Linux 竞态测试及 Linux 宿主联调。

这次发布不会自动升级已有安装；需要在 CPA 插件商店手动更新。热更新可能中断正在运行的 CodeArts 流，建议选低流量时段。
