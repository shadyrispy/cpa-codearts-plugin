# v0.1.15

包含 v0.1.14 的每日自动领取、主动领取按钮、任务总开关及单任务开关，并补齐数据库宿主的持久化支持。

- 新增 `state_dir`：可指定独立持久化目录，防止 CPA 的 PostgreSQL/对象存储后端启动时重建认证缓存目录而丢失开关和当天领取记录。
- 数据库部署请设置绝对路径，例如 `state_dir: /data/codearts-provider-state`，确保 `/data` 是持久化挂载，且该目录不在认证缓存目录内。
- 普通文件认证部署不必改配置，仍默认保存在 `auth-dir/.codearts-provider-state`。已有记录切换目录时需停机迁移；插件不会自动复制或删除它们。
- 新增模拟认证缓存重建的回归测试，并在真实 CPA 联调中验证独立目录、开关恢复和领取去重。

自动领取默认关闭；可在插件页面开启。手动「领取今日额度」不受自动开关限制。上游受理不保证额外增发额度，以「刷新福利额度」结果为准。
